# Tic-Tac-Toe (Java) ❌⭕

Klassisches Tic-Tac-Toe für 2 Spieler in der Java-Konsole.

## Technologien
- Java 17+
- 2D-Arrays für das Spielfeld
- Spiellogik: Gewinn- und Unentschiedenprüfung

## Spielregeln
- Spieler X und O setzen abwechselnd ihre Zeichen
- Zeile und Spalte (1–3) eingeben
- Wer zuerst 3 in einer Reihe hat, gewinnt!

## Kompilieren & Ausführen

```bash
cd src
javac TicTacToe.java
java TicTacToe
```
